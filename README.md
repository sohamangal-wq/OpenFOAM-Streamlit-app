# OpenFOAM-Streamlit-app-created-with-Python-Gemini-collab
My project: I am performing toxic and flammable gas leak simulations in a cubical room with an air ventilation inlet and outlet and a wall thickness for the room. I aim to measure the gas concentrations of the gases at the outlet vent using probes, and there can be single or multiple leaks with different release properties like temp, pressure, leak orientation, gas species, concentration, molecular weight, etc. The HVAC air has a fixed velocity. I also want to do gas mapping for open-to-air oil & gas or chemical plants (I will import an STL of the plant). I'm building a Streamlit UI that uses Python scripts to help me run my OpenFOAM cases through the Streamlit interface. 
Automation of OpenFOAM v13 closed-room batch leak simulations and visualization within a web app made using Streamlit web app as the host.
All Python script files were created by prompting Gemini Pro.
All OpenFOAM case files are automatically created by the Python scripts while running a simulation.
The aim is to automate the usage of OpenFOAM V13 as much as possible and enable continuous overnight simulation runs  for various leak scenarios defined inside a closed volume/room that has HVAC inlet and outlet vents.
